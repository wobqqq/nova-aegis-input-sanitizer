# Security policy

## Supported versions

Only the latest release receives security fixes. Update with `composer update wobqqq/nova-aegis-input-sanitizer`.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub security advisories](https://github.com/wobqqq/nova-aegis-input-sanitizer/security/advisories/new) with the steps to reproduce it and the versions of the module, the Aegis core, Laravel Nova, Laravel and PHP.

A payload that the default patterns miss is welcome too: report it the same way, without testing it against sites you do not own.

You will get an answer within five working days. Once a fix is released the advisory is published with credit to the reporter, unless you prefer otherwise.
